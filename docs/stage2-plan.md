# 2단계 계획: 액션·설정·OSD

1단계(M1)에서 훅과 판정을 검증했다. 2단계는 그 위에 실제로 쓸 수 있는 덱을 만든다. 편집기 화면은 3단계이므로, 2단계에서는 설정 파일(JSON)을 직접 고쳐서 버튼을 바꾼다.

## 통과 기준 (M2)

1. 직접 쓴 JSON 설정으로 모든 액션 종류가 실행된다.
2. 설정 파일을 저장하면 재시작 없이 바로 반영된다. 잘못된 설정을 저장해도 앱이 죽지 않고 직전 설정을 유지한다.
3. OSD가 포커스를 뺏지 않고 클릭이 아래 창으로 통과한다.
4. 트레이 아이콘이 숫자 모드·덱 모드·일시정지를 구분해 보여주고, 일시정지 중에는 넘패드가 평소처럼 동작한다.
5. 세션 잠금 해제·절전 복귀 뒤에도 덱이 반응한다.

## 진행 순서

코어를 먼저 완성하고 화면을 나중에 붙인다. 2-1부터 2-3까지는 콘솔 프로브로 검증할 수 있다.

| 순서 | 작업 | 위치 | 검증 |
| --- | --- | --- | --- |
| 2-1 | 설정 스키마·로더·파일 감시 | `core/src/config.rs` | 단위 테스트, 프로브에서 저장 즉시 반영 |
| 2-2 | 덱 상태(현재 페이지)와 디스패처 | `core/src/deck.rs` | 단위 테스트 |
| 2-3 | 액션 실행기 | `core/src/action/` | 프로브 `--config`로 실제 액션 실행 (M2-1, M2-2) |
| 2-4 | Tauri 셸: 트레이·일시정지·자동 재설치 | `app/` | 수동 (M2-4, M2-5) |
| 2-5 | OSD | `app/` | 수동 (M2-3) |

## 2-1 설정

- **위치**: `%APPDATA%\NumpadDeck\config.json`. 없으면 기본 설정을 만든다(프로토타입의 미디어·창 관리 페이지를 옮긴 것). 정식 프리셋은 3단계에서 만든다.
- **저장**: 임시 파일에 쓴 뒤 이름을 바꾼다. 앱이 쓴 변경은 감시에서 다시 반영하지 않는다.
- **감시**: `notify` 크레이트로 파일 변경을 감지하고, 짧게 모아서(약 200ms) 한 번만 다시 읽는다. 읽기나 검증에 실패하면 직전 설정을 유지하고 오류를 알린다.
- **스키마 버전**: 최상위 `version` 필드. 형식이 바뀌면 이전 버전을 변환한다.

사람이 읽고 고치기 쉽도록 버튼은 배열 순서가 아니라 키 이름으로 적는다. 빈 키는 생략한다.

```json
{
  "version": 1,
  "pages": [
    {
      "name": "미디어",
      "buttons": {
        "7": { "label": "이전곡", "action": { "type": "media", "command": "prev" } },
        "8": { "label": "재생/정지", "action": { "type": "media", "command": "playPause" } },
        "+": { "label": "회의 음소거", "action": { "type": "micMute" } },
        "Enter": {
          "label": "캡처 후 그림판",
          "action": {
            "type": "sequence",
            "steps": [
              { "type": "hotkey", "keys": ["Win", "Shift", "S"] },
              { "type": "delay", "ms": 3000 },
              { "type": "launch", "target": "mspaint.exe" }
            ]
          }
        }
      }
    }
  ]
}
```

`label`은 OSD에 표시할 이름이다. `icon` 필드 자리는 남겨 두고 아이콘 세트는 3단계에서 채운다.

## 2-3 액션

| `type` | 필드 | 구현 |
| --- | --- | --- |
| `hotkey` | `keys`: 키 이름 배열 | `SendInput`. 사용자가 누르고 있는 보조 키(Shift 등)는 보내기 전에 떼고 끝난 뒤 되돌린다 (M1 한계). |
| `launch` | `target`, `args`(선택) | 실행 중이 아니면 실행한다. 실행 중이면 그 앱의 가장 최근 창을 앞으로 가져온다. 이미 맨 앞이면 같은 앱의 다음 창으로 넘긴다(창이 하나면 그대로 둔다). 포그라운드 잠금 우회 포함. 스토어 앱은 `shell:AppsFolder\<AUMID>`. |
| `open` | `target`: URL 또는 폴더 | `ShellExecuteW` |
| `text` | `text` | `KEYEVENTF_UNICODE` (한글 입력기 상태와 무관) |
| `media` | `command`: `playPause` `next` `prev` `stop` `volumeUp` `volumeDown` `volumeMute` | 미디어 가상 키 주입. Windows 볼륨 표시가 그대로 뜬다. |
| `micMute` | — | Core Audio로 연결된 모든 녹음 장치의 음소거 토글. 하나라도 켜져 있으면 전부 음소거, 전부 음소거면 전부 켬 (기본 장치만 바꾸면 오디오 인터페이스가 빠짐: M2 실측) |
| `sound` | `file`, `volume`(선택, 0–1) | `rodio`로 재생. WAV·MP3·OGG·FLAC 지원, 연타하면 겹쳐 재생 |
| `sequence` | `steps`: 액션 배열 | 순서대로 실행. 사이에 `{ "type": "delay", "ms": N }`을 넣을 수 있다. |

- 실행기는 전용 스레드 하나에서 큐를 처리한다. 훅 스레드는 큐에 넣기만 한다.
- 지연이 긴 묶음이 실행 중일 때 다른 버튼을 누르면 기다리지 않고 바로 실행되도록, 묶음은 별도 작업으로 돌린다.
- 액션 하나가 실패해도 실행기는 계속 돈다. 실패는 이벤트로 알린다(2단계에서는 로그, 이후 트레이 알림).
- 모든 주입 입력에는 `inject::SIGNATURE`를 붙인다.

## 2-4 Tauri 셸

- 위치는 저장소의 `app/`(Tauri 2 + React + TypeScript + Tailwind + shadcn/ui, npm). `core`를 경로 의존성으로 쓰고 워크스페이스에 넣는다.
- **트레이 아이콘** 세 가지: 숫자 모드, 덱 모드, 일시정지. 메뉴: 일시정지/재개, 설정 파일 열기, 종료.
- **모드 표시**: 훅이 NumLock 키 이벤트를 알리면 앱이 상태를 다시 조회해 아이콘을 바꾼다. 다른 프로그램이 NumLock을 바꾸는 경우를 대비해 짧은 주기로도 확인한다.
- **일시정지**: 훅의 판정을 끄고 모든 입력을 통과시킨다. 훅 자체는 유지한다.
- **자동 재설치**: 숨은 창으로 세션 잠금 해제(`WTSRegisterSessionNotification`)와 절전 복귀(`WM_POWERBROADCAST`)를 받아 훅을 다시 설치한다.
- 자동 실행·설치 파일은 4단계다.

## 2-5 OSD

- 창 하나를 미리 만들어 숨겨 둔다. 투명 배경, 캡션 없음, 항상 위, 작업 표시줄에 안 나옴.
- `WS_EX_NOACTIVATE | WS_EX_TRANSPARENT | WS_EX_TOOLWINDOW`를 `windows-rs`로 직접 지정하고 `SW_SHOWNOACTIVATE`로 띄운다.
- **위치**: 마우스가 있는 모니터의 우측 하단, 작업 표시줄 위.
- **표시 시간**: 페이지 전환 2.5초, 버튼 실행 0.8초(누른 버튼 강조), NumLock 전환 1초(모드 이름), `-` 키는 띄우기/숨기기 토글. 위치·시간 설정은 3단계 편집기에서.
- **내용**: 페이지 번호와 이름, 넘패드 모양 그리드(버튼 12개 라벨, 시스템 키는 흐리게).

## 미정·위험

- 포그라운드 잠금 우회는 환경에 따라 실패할 수 있어 2-3에서 실측한다.
- WebView2 창을 `SW_SHOWNOACTIVATE`로 띄워도 포커스를 가져가지 않는지 2-5에서 가장 먼저 확인한다. 실패하면 OSD만 Win32 창으로 직접 그리는 방안을 검토한다.
  - 결과(2-5): 포커스를 뺏지 않음. 대신 WebView2 상주 메모리가 커서(GPU 사용 약 223MB) GPU 가속을 끄기로 함(약 116MB, 화면 동일). Win32 직접 그리기(약 10MB 예상)는 필요해지면 다시 검토.
