# Numpad Deck 사용해 보기 (시험 안내)

시간 내 주셔서 고맙습니다. Numpad Deck은 키보드 오른쪽 숫자 패드(넘패드)를 **버튼 패드**로 바꿔 주는 프로그램이에요. NumLock을 끄면 넘패드 키 하나하나가 "음악 재생", "유튜브 열기" 같은 버튼이 되고, NumLock을 켜면 원래처럼 숫자가 입력돼요.

이번 시험은 **프로그램이 얼마나 쉬운지**를 보는 것이지, 여러분을 평가하는 게 아니에요. 막히는 곳이 있으면 그건 프로그램의 잘못이니 편하게 적어 주세요. 설명서를 따로 드리지 않는 것도 일부러예요. 화면 안내만 보고 해 주세요.

## 준비물

- Windows 10 또는 11 PC
- **넘패드(숫자 패드)가 있는 키보드.** 노트북 자판에 Fn 키로 쓰는 숫자 패드는 지원하지 않아요. 노트북이라면 넘패드 있는 USB 키보드를 연결하거나, 없으면 그 사실도 결과에 적어 주세요.
- 20–30분

## 설치

1. 받은 `Numpad Deck_0.2.0_x64-setup.exe`를 실행하세요.
2. **"Windows의 PC 보호"** 파란 창이 뜨면 `추가 정보` → `실행`을 누르세요. 아직 정식 서명 전인 시험판이라 뜨는 경고예요.
3. 설치가 끝나면 Numpad Deck이 자동으로 실행돼요. 실행되지 않으면 시작 메뉴에서 Numpad Deck을 여세요.

> 이 프로그램은 넘패드 키를 버튼으로 쓰려고 키 입력을 확인하지만, 키 입력을 **저장하거나 어디로 보내지 않아요.**

## 해 볼 일

순서대로 해 주세요. 각 일마다 **된 / 헤맸지만 됨 / 못 함** 중 하나와, 헤맸다면 어디서 헤맸는지 적어 주세요. 1번은 걸린 시간도 대략 적어 주세요(시계를 보고 시작하세요).

1. **처음 안내를 따라 넘패드 버튼을 하나 눌러 보기.** (시작 시각: ____ 버튼이 처음 동작한 시각: ____)
2. 아무 버튼이나 골라 **이름과 아이콘을 바꾸기.** 그다음 넘패드로 눌렀을 때 화면 오른쪽 아래 표시에 바뀐 이름이 보이는지 확인.
3. **새 페이지를 하나 만들고** 이름을 마음대로 바꾸기. 넘패드로 그 페이지로 넘어가 보기.
4. 새 페이지에 **아래 동작을 하는 버튼**을 하나씩 만들고 넘패드로 눌러 보기.
   - a. 내가 자주 쓰는 **프로그램 열기** (예: 메모장, 카카오톡)
   - b. 자주 가는 **사이트 열기**
   - c. **단축키 보내기**: 복사(Ctrl+C) 또는 붙여넣기(Ctrl+V)
   - d. 자주 쓰는 **문장 입력하기** (예: 내 이메일 주소)
   - e. **볼륨 높이기**
   - f. **마이크 끄기/켜기**
   - g. **효과음 내기**: 소리 파일은 `C:\Windows\Media` 폴더 안 아무 파일이나 써도 돼요.
   - h. **여러 동작을 차례로**: 예) 메모장 열기 → 1초 기다리기 → 문장 입력하기
5. 실수로 버튼 하나를 지웠다고 생각하고 **되돌려 보기.**
6. 화면 글자를 **영어로 바꿨다가 다시 한국어로** 돌려 보기.
7. 화면 오른쪽 아래 작업 표시줄에서 **Numpad Deck 아이콘을 찾아** 잠깐 **일시정지**했다가 다시 켜 보기.
8. (노트북 등) 화면에 보이는 넘패드 모양이 **내 키보드와 다르면** 내 키보드 모양으로 맞춰 보기. 페이지 넘기는 키가 불편한 자리에 있으면 바꿔 보기.

## 결과 적는 칸

복사해서 메시지로 보내 주셔도 돼요.

```
PC: (예: 데스크톱 Windows 11 / 노트북 + USB 키보드)
넘패드 있는 키보드: 예 / 아니요

1. 처음 버튼:      된 / 헤맸지만 됨 / 못 함   걸린 시간: 약 __분   헤맨 곳:
```

## 끝나면

계속 쓰셔도 되고, 지우려면 Windows `설정` → `앱` → `설치된 앱`에서 Numpad Deck을 제거하세요. 설정은 `%APPDATA%\NumpadDeck` 폴더에 남아 있으니 깨끗이 지우려면 이 폴더도 지우세요.
